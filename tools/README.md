## Specialized Hardware

### Processing Units
- **CPUs**: General-purpose processors
- **GPUs**: Graphics processing units for parallel computing
  - NVIDIA GPUs (Tesla, RTX series)
  - AMD GPUs
- **TPUs**: Google's Tensor Processing Units
- **FPGAs**: Field-programmable gate arrays
