# Banners

Social/hero banners for major sections. Place PNG/JPG files here.

Naming: `<section>-hero.png` (e.g., `ai-agents-hero.png`, `nlp-hero.png`).

Suggested size: 1200×630 (Open Graph), < 1MB.

Usage example in a README:

```markdown
![banner](../../assets/banners/ai-agents-hero.png)
```

Sections: `domains/*`, `reference/`, `infrastructure/`.
